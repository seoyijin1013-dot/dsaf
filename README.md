# 한동민의 iPhone

한국대학교 실용음악과 2학년 한동민의 가상 휴대폰 웹사이트입니다

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다
2. 이 폴더의 **내용물**을 저장소 루트에 업로드합니다 (`index.html`이 최상위)
3. Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다
4. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 Save를 누릅니다
5. 배포 완료 후 Pages에 표시되는 사이트 주소를 엽니다

서버, API 키, 설치, 빌드 명령이 필요하지 않습니다
잠금 비밀번호는 `0000`이며 방문자에게도 소스가 공개되는 연출용 설정입니다

## 파일 구성
- `index.html`: 휴대폰 프레임과 화면 영역
- `css/style.css`: 화면 및 앱 스타일
- `assets/images/`: 배경, 앨범, 프로필 및 아이콘 이미지
- `js/01-...`부터 `js/11-...`: 기존 기능을 보존한 화면·데이터 모듈
- `js/chat-engine.js`: 최신 인물별 자동 답장 규칙과 순차 전송 큐
- `js/app-final.js`: 최종 앱 진입 및 음악 앱
- `AUTOREPLIES.md`: 자동 답장 설명과 응답 문구

스크립트는 index.html에 적힌 순서로 실행해야 합니다
기존 화면 호환을 위해 일부 이전 함수가 남아 있고, 뒤쪽 파일의 최신 정의가 우선합니다
단순히 파일만 합치거나 실행 순서를 바꾸면 안 됩니다

## 변경 사항
- 홈화면 스포티파이 앱 제거
- 인스타 프로필 하이라이트 제거
- 잠금화면 음악 위젯과 하단 음악 앱 유지
- 자동 답장은 좋아해, 똥개의 일상, 돼지, 펌킨팍, 상혁이형에게만 적용
- 해당 인물의 알려진 인스타 계정에서도 같은 성격 적용
- 그룹방, 공지방, 엑스트라는 메시지를 보낼 수 있지만 자동 답장은 없음

## 저장과 초기화
새로고침할 때마다 메시지, 대화 진행, 읽음 상태, 스토리 열람 상태가 처음으로 돌아갑니다
페이지를 열어둔 동안의 대화는 유지됩니다
기존 버전의 저장 데이터도 페이지 시작 시 이 사이트의 두 저장 키만 지웁니다
`js/reset-on-load.js`는 다른 스크립트보다 먼저 실행해야 합니다
브라우저 전체의 저장 데이터는 삭제하지 않습니다

## 몰입형 답장 업데이트
- 습득자라고 밝히기 전에는 한동민으로 인식하며, 밝힌 뒤에는 존댓말로 폰 반환 안내
- 동현: 우리 무슨 사이 질문에는 머뭇거림, 습득자가 묻는 관계에는 친구라고 답함
- 동현: 좋아한다고 말하면 놀람 → 진심 확인 → 생각할 시간 → 만나서 이야기하는 흐름
- 동현: 습득자에게는 동민이 마음을 대신 판단하지 않고 직접 물어보겠다고 답함
- 다섯 인물 모두: 폰을 찾았다는 말에 안도하는 응답
- 상혁: 동현이에게 마음을 들킨 것 같다는 상담과 후속 대화
- 카카오톡 발신 말풍선 오른쪽 여백 8px
- 카톡과 DM 대화 상태는 대화방별로 구분

## 음악
음원은 포함되어 있지 않습니다
하단 음악 앱에서 재생 권한이 있는 음원 파일을 선택하면 해당 브라우저에서 재생합니다
선택한 로컬 파일은 GitHub로 업로드되거나 다른 방문자에게 공유되지 않습니다
음악 길이와 화면 연출은 기존 설정인 7:27을 기준으로 합니다

## 제한
규칙형 답장이므로 임의의 모든 문장을 이해하지 않습니다
상태는 대화방별이며 카톡과 DM 사이에서 자동으로 공유하지 않습니다
실제 전화·메시지 전송·인스타 서비스 연결은 하지 않습니다
크기가 큰 구조 변경 없이 기존 화면을 유지하려고 호환 레이어를 남겼습니다
코드의 문법, 링크 경로와 답장 분기는 검사했지만 실제 브라우저 시각 검수는 하지 않았습니다
게시 전 사진·아이콘 등 제3자 자료의 이용 권한을 확인하세요
